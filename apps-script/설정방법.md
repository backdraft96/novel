# 방문자 수 · 방명록 설정 방법 (구글 시트 + Apps Script)

처음 한 번만 하면 됩니다. 약 5분 정도 걸립니다.

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름은 자유롭게 정하면 됩니다(예: `댐 홈페이지 데이터`).
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 기본 코드를 모두 지우고, 이 폴더에 있는 `Code.gs` 내용을 붙여 넣은 뒤 **저장**합니다.
4. 위쪽 함수 선택 상자에서 `setup`을 고르고 **실행**을 누릅니다.
   - 권한 요청 창이 뜨면 본인 계정을 선택합니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다.
   - 실행이 끝나면 시트에 `방문자` 탭과 `방명록` 탭이 생깁니다.
5. **배포 → 새 배포**를 누르고, 톱니바퀴에서 유형을 **웹 앱**으로 선택합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누른 뒤 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 저장소의 `site-config.js`를 열어 `API_URL: ''` 따옴표 안에 복사한 URL을 붙여 넣고 저장(커밋)합니다.

## 관리

| 하고 싶은 일 | 방법 |
|---|---|
| 방명록 글 삭제 | `방명록` 탭에서 해당 행 삭제 |
| 글을 지우지 않고 숨기기 | 해당 행 D열(숨김)에 `Y` 입력 |
| 날짜별 방문자 확인 | `방문자` 탭 |
| 누적 방문자 시작 값 조정 | `방문자` 탭에 과거 날짜 행을 추가하고 방문수 입력 |

- 방문자는 **브라우저 한 곳당 하루 1회**만 집계됩니다. 표지나 각 장으로 바로 들어와도 똑같이 집계됩니다.
- Apps Script 코드를 고친 경우에는 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포** 순서로 다시 배포합니다. 이렇게 하면 URL이 바뀌지 않습니다.
